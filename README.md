# 🎮 Simon Says Game

> A fun and interactive memory game built with **HTML, CSS, and JavaScript**. 🧠🎨

**Simon Says Game** is a browser-based memory challenge where players must remember and repeat an increasingly complex sequence of colors. Each successful round adds a new color to the sequence, testing the player's memory and reaction skills.

## 🌐 Live Demo

🎮 **[Play Simon Says Game](https://mahiverma017.github.io/Simon-Says-Game/)**

## 🚀 How to Play

1. Click **Start** to begin the game.
2. Watch carefully as a color flashes.
3. Click the colors in the same sequence.
4. Each successful level adds **one new color**.
5. Continue remembering and repeating the sequence.
6. A wrong click results in **Game Over**.

## ✨ Features

* 🧠 Progressive difficulty
* 🎨 Interactive color buttons
* ⚡ Visual flashing effects
* 🏆 Level-based gameplay
